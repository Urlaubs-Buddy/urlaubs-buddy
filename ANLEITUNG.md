# Urlaubs-Buddy PWA

## Einrichtung auf GitHub Pages (einmalig, ca. 5 Minuten)

### Schritt 1: GitHub-Konto erstellen
1. Gehen Sie zu: https://github.com
2. Klicken Sie auf "Sign up"
3. E-Mail, Passwort, Benutzername eingeben
4. Kostenloses Konto wählen

### Schritt 2: Neues Repository erstellen
1. Nach dem Login: grüner Button "New" (oben links)
2. Repository name: `urlaubs-buddy`
3. Häkchen bei "Public"
4. Klicken Sie auf "Create repository"

### Schritt 3: Dateien hochladen
1. Klicken Sie auf "uploading an existing file"
2. Alle 5 Dateien aus diesem Ordner hochladen:
   - index.html
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png
3. Klicken Sie auf "Commit changes"

### Schritt 4: GitHub Pages aktivieren
1. Im Repository: Klicken Sie auf "Settings" (oben)
2. Links im Menü: "Pages"
3. Bei "Branch": main auswählen → Save
4. Warten Sie ca. 1 Minute

### Schritt 5: App aufrufen
Ihre App ist jetzt erreichbar unter:
https://IHR-BENUTZERNAME.github.io/urlaubs-buddy/

### App auf dem Handy installieren (PWA)
**Android (Chrome):**
1. App-URL im Chrome öffnen
2. Drei-Punkte-Menü → "Zum Startbildschirm hinzufügen"

**iPhone (Safari):**
1. App-URL in Safari öffnen
2. Teilen-Symbol → "Zum Home-Bildschirm"

**PC (Chrome/Edge):**
1. App-URL öffnen
2. In der Adressleiste erscheint ein Install-Symbol
3. Darauf klicken → "Installieren"
